# 🃏 بلوت - لعبة كملنا الرقمية

لعبة بلوت (Baloot) رقمية متكاملة تحاكي تجربة لعبة "كملنا" الشهيرة مع ذكاء اصطناعي متقدم وواجهة تفاعلية سلسة.

## ✨ المميزات

### 🎮 أنظمة اللعب
- **لعب فردي**: ضد 3 بوتات ذكية بمستوى احترافي
- **لعب جماعي**: غرف أونلاين مع لاعبين حقيقيين
- **جلسات VIP**: غرف خاصة للمحترفين

### 🤖 ذكاء اصطناعي متقدم
- **استراتيجية شراء ذكية**: البوت يحلل قوة اليد ويقرر الشراء/التمرير
- **ذاكرة الأوراق**: يقيد الأوراق النازلة ويحسب الاحتمالات
- **التنقيع**: يعرف متى يكون اللون خاوياً
- **الأوراق القاطعة**: يحسب احتمال وجود الآسات
- **لعب جماعي**: يدعم الشريك (كبش) ويحمي ورقه

### 🎯 قوانين اللعبة الكاملة
- ✅ توزيع 5 + 3/2 أوراق
- ✅ أنواع المشتري: صن (26 نقطة)، حكم (16 نقطة)
- ✅ خيارات: أول (شكل)، ثاني، الشرط
- ✅ المشاريع: سرا، خمسين، مية، أربع مية، بلوت
- ✅ حساب النقاط التلقائي (الأبناط)
- ✅ مخالفة الحكم (81 نقطة)
- ✅ نهاية اللعبة عند 152 نقطة

### 🎨 واجهة المستخدم
- 🎴 طاولة مربعة كلاسيكية بـ 4 مقاعد
- ⚡ أنيميشن سريع وسلس لرمي الأوراق
- 📊 لوحة نقاط تفاعلية
- 💬 دردشة سريعة مع إيموجيز
- 📱 تصميم متجاوب (Responsive)

### 🔒 نظام منع الغش
- ✅ التحقق من اتباع الرمز (Follow Suit)
- ✅ كشف الأخطاء في الحكم
- ✅ تتبع الأوراق
- ✅ كشف الأنماط المشبوهة

## 🎮 كيفية اللعب

### 1. البداية
- اختر وضع اللعب (فردي/جماعي)
- في الوضع الفردي: تلعب ضد 3 بوتات

### 2. التوزيع
- يوزع 5 أوراق لكل لاعب
- تُكشف ورقة المشتري

### 3. المزاد
- اختر: صن، حكم، أول، أو تمرير
- البوتات تقرر بناءً على قوة أوراقها

### 4. إكمال التوزيع
- 3 أوراق إضافية (أول) أو 2 (حكم)

### 5. المشاريع
- تُعلن تلقائياً: سرا، خمسين، مية، بلوت

### 6. اللعب
- اتبع الرمز المطلوب
- في الحكم: لعب الحكم إذا خاويت

### 7. النقاط
- آخر صكة = 10 نقاط
- المشاريع تُضاف للمجموع
- في الحكم: يجب تحقيق 81 نقطة

## 📝 API

### WebSocket Events

#### Client → Server
```javascript
// إنشاء غرفة
{ type: 'CREATE_ROOM', settings: { mode: 'solo' } }

// الانضمام لغرفة
{ type: 'JOIN_ROOM', roomId: 'ABC123' }

// المزاد
{ type: 'PLAYER_ACTION', action: { type: 'BID', bid: 'sun' } }

// لعب ورقة
{ type: 'PLAYER_ACTION', action: { type: 'PLAY_CARD', card: { suit: 'hearts', rank: 'A' } } }

// دردشة
{ type: 'PLAYER_ACTION', action: { type: 'CHAT', emoji: '🔥' } }
```

#### Server → Client
```javascript
// توزيع أوراق
{ type: 'cardsDealt', data: { player: 0, cards: [...] } }

// ورقة المشتري
{ type: 'buyerCardRevealed', data: { card: {...} } }

// تغيير الدور
{ type: 'turnChanged', data: { currentPlayer: 1 } }

// فوز بالصكة
{ type: 'trickWon', data: { winner: 0, points: 25 } }

// نهاية الجولة
{ type: 'roundEnded', data: { scores: {...} } }
```
