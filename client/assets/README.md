# Card Assets

This folder should contain card images for the game.

## Required Images

Each card needs an image file named: `{suit}_{rank}.png`

### Suits:
- hearts (♥) - دلّة
- diamonds (♦) - شيري  
- clubs (♣) - كَبّة
- spades (♠) - حُكُم

### Ranks:
- 7, 8, 9, 10, J, Q, K, A

### Example filenames:
- hearts_A.png
- spades_J.png
- diamonds_10.png
- clubs_7.png

## Total: 32 images

You can use any standard playing card images or create custom ones.
Recommended size: 200x300 pixels per card.

## Alternative: SVG Icons

The game can also run using CSS-generated cards (emoji-based) without images.
This is the default mode if no images are found.
